Real background music (keeps playing with the screen off / other apps open):
1. Put your mp3 files in this folder (public/music/).
2. List them in tracks.json, like:
   [
     { "title": "My Song", "url": "/music/my-song.mp3" },
     { "title": "Song 2",  "url": "/music/song2.mp3" }
   ]
3. Redeploy. (Or use /music-admin.)
