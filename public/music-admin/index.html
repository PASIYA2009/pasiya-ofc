Music Admin

Add songs, switch them on / off, delete them. Songs are saved to your GitHub repo (public/music), and the site updates after Vercel redeploys (about a minute).

This page is for the admin only. Log in with the admin account first.

GitHub connection

Token: GitHub > Settings > Developer settings > Fine-grained tokens > only this repo > Contents: Read and write. It is kept only in this browser and sent only to GitHub.
